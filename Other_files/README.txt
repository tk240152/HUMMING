めげるな！ハミングくーん　README

--ゲームの起動方法--
executable_file.zipを解凍し中のHUMMING.exeを起動
ビルド起動方法
HUMMINGフォルダをVSCodeで開き、App.javaにてRunで起動

--目的--
ハチドリのハミングくんを動かして、花の蜜を吸って食事を成功させよう。
ですがプレイヤーのあなたはハチドリ歴なしのひよっこ。上手に食事ができるかな？

--操作説明--

メニュー画面

WASDキーまたは矢印キーでカーソル移動
Enterキーで決定　ESCキーで戻る
F12キーでフルスクリーンの切り替え

ゲーム画面

WASD　キーでハミング君の移動

無事満腹になるとゲームクリア！
タイムに応じたクリアランクがあなたにつけられる。めざせSSランク！！
